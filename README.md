# Nold Clicker

Автокликер: зажал кнопку мыши — она начинает кликать сама.

**Автор: MawtainDew**

## Как пользоваться

1. Запусти `Hold Clicker.exe`
2. Отметь кнопки мыши и выставь частоту (CPS)
3. В игре или программе просто зажми эту кнопку

⚡ 300 CPS максимум — дальше может лагать.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| F6 | включить / выключить автоклик |
| F8 | аварийная остановка |

Клавиши можно переназначить в окне программы.

## Файлы

| Файл | Назначение |
|---|---|
| `Hold Clicker.exe` | программа |
| `_internal` | служебные файлы — не удаляй |
| `%LOCALAPPDATA%\HoldClicker\config.json` | твои настройки |
| `%LOCALAPPDATA%\HoldClicker\crash.log` | журнал ошибок |
